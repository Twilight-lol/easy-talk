# Easy Talk

Voice dictation for **Windows** and **Android**. Talk, and clean, properly punctuated text appears wherever you're typing.

## Download

Get the latest version from [Releases](https://github.com/Twilight-lol/easy-talk/releases/latest):

- **Windows:** `Easy.Talk_x.y.z_x64-setup.exe`. Windows may warn that the app is unrecognized because it isn't code-signed yet. Click **More info → Run anyway**. The app updates itself after that.
- **Android:** `EasyTalk-x.y.z-android.apk`. Allow installing from your browser or file manager when asked. Setup walks you through the permissions.

## What it does

- **Dictate anywhere.** On Windows, hold **Ctrl + Space**. On Android, tap the floating bubble.
- **AI clean-up** fixes grammar and punctuation, removes "um"s, applies corrections like "at 2… actually, make it 3", and formats lists, money, times and email addresses.
- **A tone for each app:** casual in chats, formal in email, exact wording in code editors.
- **Translate as you speak** into the language you choose.
- **Voice Edit:** select text and say "make this shorter".
- **Offline mode:** speech recognition, clean-up and translation that run entirely on your device.
